Любимыч & Микитич — как открыть и выложить сайт
================================================

1) Открыть сразу на компьютере
   Откройте файл index.html двойным щелчком
   (лучше через браузер: Chrome / Firefox / Edge).
   Папка media должна лежать рядом с index.html.

2) Выложить в интернет
   Загрузите ZIP-архив на любой хостинг статических сайтов:

   • GitHub Pages
   • Netlify (просто перетащите ZIP)
   • Vercel
   • Timeweb / Beget / REG.RU — «статический сайт»
   • любой обычный хостинг: распакуйте ZIP в public_html

   Главное: index.html должен быть в корне сайта,
   папка media/ — рядом с ним.

3) Состав
   index.html
   favicon.svg
   media/
     фото персонажей, галерея, видео, звук чоканья
